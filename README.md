# MKCL Launcher
轻量我的世界启动器，主打**多客户端管理**

## 介绍
MKCL 是一款完整发布版 Minecraft 启动器，保留普通启动器全部基础能力，同时强化多实例管理能力，支持多客户端并行运行、独立进程控制、实例自定义命名，适合多开、多版本测试、多账号游玩场景。

## ✨ 特色核心功能
### 1. 多客户端并行启动
- 支持同时运行多个 Minecraft 游戏实例
- 不同版本、不同模组配置的客户端可以并行运行，实例之间相互隔离互不干扰

### 2. 单独停止指定游戏进程
- 可在运行列表精准选中某一个游戏实例，单独终止对应 Minecraft 进程
- 仅关闭选中客户端，其余正在运行的游戏实例不受影响，无需全部重启

### 3. 客户端自定义名称显示
- 每个游戏实例支持设置自定义名称
- 运行列表直观展示实例名称，方便区分生存、测试、服务器等不同用途的客户端

## 🎯 标准启动器完整基础功能
- ✅ 实例管理：新建、编辑、删除游戏实例
- ✅ JVM 配置：自定义 Java 路径、分配内存、自定义 JVM 启动参数
- ✅ 游戏设置：窗口大小、全屏模式、游戏目录自定义
- ✅ 游戏日志输出：实时查看游戏运行日志，方便排查启动报错
- ✅ 本地游戏加载：导入已有的 Minecraft 游戏文件
- ✅ 实例文件夹隔离：每个实例拥有独立配置、模组、存档目录

## 🧩 下载中枢（PCL 风格）
「下载」页整合为 **客户端 / 模组 / 整合包** 三段式，沿用 PCL 的下载交互与并发下载管线
（与官方源共用 `DownloadManager`），模组与整合包数据来自 **Modrinth** 公开 API（免费、无需密钥）。

### 1. 客户端下载（含模组端安装）
- 浏览 / 搜索官方版本清单，切换 BMCLAPI 镜像或 Mojang 官方源后下载原版客户端
- 「安装模组端」面板：选择 **原版版本 + 加载器（Fabric / Quilt / Forge / NeoForge）+ 加载器版本**，一键安装为可直接启动的模组客户端
  - Fabric / Quilt：纯元数据安装（自动写入 `inheritsFrom` 版本 json 并下载所需库 / 客户端 / 资源，**无需运行 Java**）
  - Forge / NeoForge：下载官方安装器并使用本机 Java 运行 `--installClient` 完成安装（需已配置合适 Java）

### 2. 下载单个模组（Mods）
- 按关键词搜索 Modrinth 上的模组，可按 **MC 版本** 与 **加载器（Fabric / Forge / Quilt / NeoForge）** 过滤
- 选择模组后，指定一个已存在的游戏版本作为目标，点击「下载到该版本」
- **自动展示并下载「前置依赖」**：下载时会解析该模组的必需依赖（如 Fabric API 等库），默认一并下载到 `mods` 目录（可取消勾选），详情区会列出全部前置（必需 / 可选）
- 模组 `.jar` 会被下载到该版本对应的 `mods` 目录（自动套用隔离/共享目录规则），启动对应版本即可生效

### 3. 导入整合包（Modpacks）
- 搜索 Modrinth 整合包（`.mrpack`），选择版本后点击「导入为整合包客户端」
- 选择「基础加载器版本」（需先在「下载」页准备好对应的 Forge / Fabric 等版本）并填写实例名称
- 启动器会下载并解压整合包，把内嵌的模组/配置导入为一个**独立实例**（自动写 `inheritsFrom` 版本 json）
- 导入完成后到「版本选择」设为当前版本即可启动

> 下载源仍可在「下载 / 客户端」页切换 BMCLAPI / 官方源；模组与整合包走 Modrinth CDN，不受镜像源影响。

## 📖 使用教程
1. 启动 MKCL，创建新游戏实例
2. 配置 Java 路径、内存、游戏目录等基础参数
3. 设置实例自定义名称
4. 在「下载」页的「客户端」分段下载原版客户端；需要模组客户端时，用同页「安装模组端」面板安装 Fabric / Quilt / Forge / NeoForge
5. 在「下载」页的「模组」分段搜索并下载模组（含前置依赖）到目标版本，或在「整合包」分段导入 Modrinth 整合包
6. 启动一个或多个游戏客户端
7. 在运行实例列表中，可查看所有正在运行的客户端，支持单独停止指定实例
8. 遇到启动异常可查看游戏日志定位问题

## ⚠️ 注意事项
- 强制结束游戏进程会直接终止游戏，**请务必提前保存存档，避免存档损坏**
- 需要预先安装对应版本 Java 环境
- 部分高级功能（版本自动下载、正版账号登录、模组一键安装）可按需扩展

## 📌 使用场景
- 多账号同时游玩 Minecraft
- 多版本、多模组环境对比测试
- 服务器测试多客户端联机
- 需要大量多开实例的玩家
