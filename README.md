# MKCL Launcher
轻量我的世界启动器，主打**多客户端管理**

## 介绍
MKCL 是一款完整发布版 Minecraft 启动器，保留普通启动器全部基础能力，同时强化多实例管理能力，支持多客户端并行运行、独立进程控制、实例自定义命名，适合多开、多版本测试、多账号游玩场景。

## ✨ 特色核心功能
### 1. 多客户端并行启动
- 支持同时运行多个 Minecraft 游戏实例
- 不同版本、不同模组配置的客户端可以并行运行，实例之间相互隔离互不干扰

### 2. 单独停止指定游戏进程
- 可在运行列表精准选中某一个游戏实例，单独终止对应 Minecraft 进程
- 仅关闭选中客户端，其余正在运行的游戏实例不受影响，无需全部重启

### 3. 客户端自定义名称显示
- 每个游戏实例支持设置自定义名称
- 运行列表直观展示实例名称，方便区分生存、测试、服务器等不同用途的客户端

## 🎯 标准启动器完整基础功能
- ✅ 实例管理：新建、编辑、删除游戏实例
- ✅ JVM 配置：自定义 Java 路径、分配内存、自定义 JVM 启动参数
- ✅ 游戏设置：窗口大小、全屏模式、游戏目录自定义
- ✅ 游戏日志输出：实时查看游戏运行日志，方便排查启动报错
- ✅ 本地游戏加载：导入已有的 Minecraft 游戏文件
- ✅ 实例文件夹隔离：每个实例拥有独立配置、模组、存档目录

## 📖 使用教程
1. 启动 MKCL，创建新游戏实例
2. 配置 Java 路径、内存、游戏目录等基础参数
3. 设置实例自定义名称
4. 启动一个或多个游戏客户端
5. 在运行实例列表中，可查看所有正在运行的客户端，支持单独停止指定实例
6. 遇到启动异常可查看游戏日志定位问题

## ⚠️ 注意事项
- 强制结束游戏进程会直接终止游戏，**请务必提前保存存档，避免存档损坏**
- 需要预先安装对应版本 Java 环境
- 部分高级功能（版本自动下载、正版账号登录、模组一键安装）可按需扩展

## 📌 使用场景
- 多账号同时游玩 Minecraft
- 多版本、多模组环境对比测试
- 服务器测试多客户端联机
- 需要大量多开实例的玩家

## 🛠️ 编译与运行
> 项目自带编译脚本 `编译.bat`
1. 准备好项目源码与全部依赖
2. 直接双击运行 `编译.bat` 脚本完成构建
3. 编译完成后得到可执行程序
4. 运行程序，配置好 Java 环境即可使用
